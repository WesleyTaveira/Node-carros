API RESTful de backend desenvolvida em Node.js e TypeScript, focada na gestão de veículos e marcas automóveis. Utiliza o framework Express e a biblioteca TypeORM para interagir com uma base de dados relacional PostgreSQL, permitindo a realização de operações completas de CRUD (criação, leitura, atualização e eliminação) para as entidades Carro e Marca, incluindo a gestão das relações entre elas.O sistema é totalmente contentorizado através do Docker e Docker Compose, utilizando uma construção multi-estágio (multi-stage build) para garantir um ambiente de execução otimizado e consistente.
